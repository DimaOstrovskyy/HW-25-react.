# Кінопошук

React-застосунок для пошуку та перегляду інформації про фільми з TMDB API.

## Запуск

1. Створи акаунт на TMDB та отримай API Key.
2. Відкрий файл `.env`.
3. Заміни `YOUR_TMDB_API_KEY` на свій ключ:

```env
VITE_TMDB_API_KEY=твій_ключ
```

4. Встанови залежності та запусти проєкт:

```bash
npm install
npm run dev
```

## Маршрути

- `/` — популярні фільми сьогодні
- `/movies` — пошук фільмів
- `/movies/:movieId` — детальна інформація
- `/movies/:movieId/cast` — акторський склад
- `/movies/:movieId/reviews` — відгуки
- невідомий маршрут — перенаправлення на `/`

Для сторінок використано `React.lazy()` та `Suspense`.
